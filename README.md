# 강촌 여행 안내

북한강 물가 마을 강촌(강원특별자치도 춘천시 남산면)을 소개하는 홍보 페이지입니다.

- 주소: https://eunyool10.github.io/gangchon/
- 구성: 왼쪽 사이드바의 페이지 목록으로 이동하는 여러 페이지 구성 (소개 · 가볼 곳 5곳 · 지도 · 오는 길 · 지나온 길). 출처와 사진·오픈 소스 정보는 ‘출처’ 창에 모아 두었습니다.
- 정보 확인일: 2026년 11월 27일

모든 내용은 춘천시 관광 포털, 춘천시 소식지 ‘봄내’, 강촌레일파크 누리집, 한국관광공사 관광정보, 위키백과, 언론 기사에서 확인한 사실만 담았습니다.
