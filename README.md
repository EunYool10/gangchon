# 강촌 여행 안내

북한강 물가 마을 강촌(강원특별자치도 춘천시 남산면)을 소개하는 홍보 페이지입니다.

- 주소: https://eunyool10.github.io/gangchon/
- 구성: 강촌 한눈에, 가볼 곳 6곳, 계절별 볼거리, 지도, 오는 길, 강촌 이야기(연표), 출처
- 정보 확인일: 2026년 11월 27일

모든 내용은 춘천시 관광 포털, 춘천시 소식지 ‘봄내’, 강촌레일파크 누리집, 한국관광공사 관광정보, 위키백과, 언론 기사에서 확인한 사실만 담았습니다. 출처는 페이지 맨 아래에 있습니다.
